## 📖 About the Project

While my main focus is Front-end development, this project allowed me to explore the "other side" of web development. I built it to practice HTTP methods (GET/POST), dynamic URL parameters, and Server-Side Rendering (SSR) using the EJS templating engine.

To make it visually appealing, I designed the UI from scratch using raw CSS, drawing heavy inspiration from the clean, modern look of Gmail and Google's Material Design.

> *This project was built following the curriculum from [The Odin Project](https://www.theodinproject.com/) (NodeJS Path).*

## ✨ Features

- **View Messages:** A clean inbox-style view listing all submitted messages.
- **Message Details:** Dynamic routing allows users to click on any message to view its full content on a dedicated page.
- **Send Messages:** A form that handles `POST` requests to update the server's data array and redirect the user seamlessly.
- **Responsive UI:** A custom, clean interface inspired by Gmail.

## 🛠️ Technologies

- **[Node.js](https://nodejs.org/en/)** - JavaScript runtime environment.
- **[Express.js](https://expressjs.com/)** - Fast, unopinionated, minimalist web framework for Node.js.
- **[EJS](https://ejs.co/)** - Embedded JavaScript templating engine.
- **CSS3** - For custom, modern styling.

## 💻 How to Run Locally

If you want to clone this repository and run it on your local machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/GabrielBRQ/your-repo-name.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd your-repo-name
   ```

3. **Install the dependencies:**
   ```bash
   npm install
   ```

4. **Start the server:**
   ```bash
   node index.js 
   ```

5. **Open your browser:**
   Navigate to `http://localhost:3000` (or the port specified in your code).
